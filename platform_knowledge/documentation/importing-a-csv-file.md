title: Importing a CSV file into Avenqo
tags: [import, csv, data, connections]
---

To import a CSV file into Avenqo:

1. Open **Connections** from the left navigation.
2. Click **Add data source** and choose **CSV file**.
3. Select the file from your computer. Avenqo automatically detects the columns and previews the first rows.
4. Confirm the column mapping (for example, which column is the sale date, the amount, the customer name).
5. Click **Import**. Avenqo processes the file and shows a confirmation once it's ready.

If the import fails, Avenqo shows a plain-language reason (for example, a required column is missing) — it never shows a technical error code without an explanation.
