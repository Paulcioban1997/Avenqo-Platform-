# Mirakl

- Readiness: `COMING_SOON`; no adapter is registered.
- Developer account: operator- or seller-provided Mirakl API access for a test environment.
- Registration: obtain a tenant-specific operator URL and read-only API key from the marketplace operator.
- Callback/webhook: none deployed; API-key authentication is planned.
- Scopes: read orders, offers/products, inventory, refunds, and shipments as granted by the operator.
- Environment: future `MIRAKL_OPERATOR_URL`, `MIRAKL_API_KEY`.
- Sandbox/review: availability and approval are operator-specific; there is no universal Mirakl sandbox credential.
- Acceptance: validate operator API version, role boundaries, pagination, throttling, key revocation, and the common gate.
